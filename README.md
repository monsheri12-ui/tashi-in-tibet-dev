# Таши в Тибете — разработчик

Независимый просмотр игры: https://monsheri12-ui.github.io/tashi-in-tibet-dev/

Версия 1.0.4: 7416 записей в каталоге и 109 сцен. Нужные условия действия готовятся по умолчанию. Кнопки «Проиграть действие» и «Открыть задание» переключают между результатом и исходным упражнением. Сначала выберите локацию или найдите нужную запись.

Добавлены 36 погодных примеров для дома, улицы, парка и гостиницы: дождь с дождевиком, мокрая одежда, ночь, пасмурная погода, гроза и радуга. Есть отдельная кнопка просмотра ходьбы. Доступны все 50 новых достижений, исправленные иконки и английские подписи.

Состояние просмотра начинается заново при перезагрузке. Ключи состояния, языка и звуков этого проекта отдельные. Основная игра и Тильда не получают панель разработчика.

Для публикации используются неизменная основа 1.0.2, общий рисованный комплект основной версии 1.0.6 и независимый архив `tashi-developer.zip` релиза 1.0.4 этого проекта. SHA-256 и проверка 491 ресурса закреплены в `.github/workflows/pages.yml`.

Публикация: Actions → Publish Tashi developer game → Run workflow → main.
