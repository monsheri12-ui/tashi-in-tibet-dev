# Таши в Тибете — разработчик

Отдельная версия игры с каталогом локаций и действий. Открыть: https://monsheri12-ui.github.io/tashi-in-tibet-dev/

Выберите локацию или найдите действие. Правильное время, состояние предметов и условия сцены готовятся автоматически; по умолчанию сразу показывается результат действия. Кнопка «Открыть задание» позволяет проверить исходный игровой интерфейс. Есть просмотр всех домашних поручений, действий Уши, альбома достижений, словаря и остановок путешествий.

Эта версия использует отдельное тестовое состояние; после обновления страницы просмотр начинается заново. Панель разработчика включена только здесь. Основная игра: https://foxsaywawa.tilda.ws/tashi-in-tibet

Сборка использует проверенные ресурсы основной игры 1.0.2 и независимый архив `tashi-developer.zip` из релиза этого репозитория. Обе контрольные суммы закреплены в `.github/workflows/pages.yml`. Публикация: Actions → Publish Tashi developer game → Run workflow → main. Лицензии ресурсов включены в сборку.
